# Stage 1 - Understanding How a Backend Application Works

Before learning Docker, Kubernetes, CI/CD, Cloud and SRE concepts, I wanted to understand what actually runs inside a backend application.

Instead of learning technologies separately, I tried to understand them in the same order they appear while building a real application.

This stage covers:

- How a Java program runs
- Why web servers exist
- Why Spring exists
- How APIs work
- Why databases are needed
- Why Hibernate exists
- Common production challenges
